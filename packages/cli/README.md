# Engager CLI

Run `engager init` to provision the local database and register the MCP server. Run `engager call get_status` to verify the connection. The scheduler and worker run in the foreground with `engager up`.

A free headless installation uses your local PostgreSQL server, uv and your own AI agent. The official Mac app includes the dashboard. [Engager for Mac](https://getengager.com)
